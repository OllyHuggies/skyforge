# skyforge

**Discover. Create. Fly.**

SkyForge is an upcoming platform for drone pilots, FPV enthusiasts, aerial photographers, and makers.

The goal of SkyForge is to create a single hub where users can:

* Discover and share drone flying locations
* Explore community-submitted flight footage
* Access 3D-printable drone accessories
* Connect with other drone pilots
* Plan future flights

## Current Status

🚧 Early Development

SkyForge is currently being developed as an independent project.

## Planned Features

* Drone Spot Discovery
* Community Uploads
* Flight Planning Tools
* 3D Print Hub
* Weather Integration
* Pilot Profiles

## Mission

To become the home of drone exploration and creation.
